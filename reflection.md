# Reflection

## Team 54

Since I needed a reminder of what kinds of side channel vulnerabilities there are,
I decided to review them and, while I was at it, design the app around one of them.
I originally intended to implement actual password hashing to make it a bit more realistic,
but unanticipated problems kept arising, so I simply decided to simulate it instead.

For the workflow, I started by visualizing how I wanted the app to look. Then, I designed the HTML file
in a way that matched what I had in mind. Finally, I wrote the JS file to implement the app's
functionality, making slight adjustments to the HTML file as I went.
Naturally, as I worked on each file, I would test the app in a browser to confirm that what I was doing
was working.
